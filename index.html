    What are security headers?

    Security headers are instructions a website sends with every page. They tell the browser things like "always use HTTPS", "never show this page inside another site's frame" and "do not run scripts from strangers". They cost nothing to add, and together they block whole families of attacks — clickjacking, script injection, connection downgrading and MIME sniffing. This checker looks at the six headers that matter most.
